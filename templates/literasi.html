Langkah & Isi Data Pelaporan Kasus Digital

Ikuti urutan langkah di bawah ini untuk mengamankan bukti sebelum pelaku menghapus konten atau mengganti identitas, lalu susun data laporan satu per satu.

1. Identitas & Jejak Akun Pelaku

  • Tautan (URL) lengkap: Salin URL profil pelaku serta URL spesifik unggahan, komentar, atau video bermasalah—jangan hanya mengandalkan username yang mudah diganti.
  • User ID permanen: Untuk platform seperti Facebook, Instagram, atau X, catat angka User ID permanen (misalnya melalui alat pencari ID seperti CommentPicker atau Lookup-ID) karena ID tetap ada meski nama/username berubah.
  • Informasi kontak & pembayaran: Jika interaksi lewat aplikasi pesan atau disertai pemerasan, catat nomor telepon (dengan kode negara), email, serta nomor rekening bank atau e-wallet yang dipakai.

2. Dokumentasi Visual (Bukan Sekadar Screenshot)

  • Rekam layar berkesinambungan: Rekam layar tanpa jeda mulai dari membuka aplikasi, menampilkan profil/URL pelaku, hingga menggulir ke isi pesan atau komentar bermasalah dengan tanggal dan jam perangkat terlihat.
  • Screenshot utuh: Ambil tangkapan layar penuh yang memuat konteks sebelum dan sesudah kejadian, nama akun pelaku, serta timestamp tanpa memotong tepi layar atau mencoret gambar.
  • Arsip halaman web: Jika konten/ancaman berada di halaman web atau tautan publik, simpan arsipnya melalui Wayback Machine (web.archive.org) atau Archive.today agar tercatat dengan waktu pengambilan.

3. File Orisinal & Riwayat Percakapan

  • Ekspor riwayat chat: Pada aplikasi seperti WhatsApp atau Telegram, gunakan Export Chat (sertakan media / Include Media) untuk mengunduh percakapan beserta lampiran aslinya.
  • File media asli: Simpan foto, video, atau voice note asli langsung dari penyimpanan perangkat (bukan sekadar forward atau screenshot) agar metadata aslinya tetap terjaga.
  • Header email lengkap: Untuk ancaman/perundungan via email, simpan pesan beserta header aslinya (misalnya format .eml / Show Original) yang memuat alamat IP pengirim dan jalur server.

4. Penyimpanan Aman & Butir Isi Laporan

  • Amankan akun & backup: Aktifkan 2FA dan ganti kata sandi akun pribadimu; jangan hapus chat atau blokir sebelum bukti diekspor (cukup mute/restrict). Simpan salinan di cloud dan media penyimpanan eksternal dalam folder rapi tanpa mengubah nama file asli.
  • Isi data pelaporan satu per satu: Siapkan (a) identitas pelapor & kontak, (b) waktu, zona waktu, dan platform kejadian, (c) identitas & jejak pelaku, (d) kronologi runtut dan dampak, (e) daftar lampiran bukti, serta (f) tindakan pengamanan yang sudah dilakukan.
